# Ringkasan Cepat: Kabel UTP, Crimping & Testing

## 1. Urutan Warna Standar T568B
- Pin 1: Putih-Oranye
- Pin 2: Oranye
- Pin 3: Putih-Hijau
- Pin 4: Biru
- Pin 5: Putih-Biru
- Pin 6: Hijau
- Pin 7: Putih-Cokelat
- Pin 8: Cokelat

## 2. Standar T568A
- Pin 1: Putih-Hijau, Pin 2: Hijau, Pin 3: Putih-Oranye, Pin 4: Biru, Pin 5: Putih-Biru, Pin 6: Oranye, Pin 7: Putih-Cokelat, Pin 8: Cokelat.

## 3. Aturan Crimping
- Jaket luar kabel harus masuk ke dalam bodi pengunci RJ45.
- Kupas jaket 2-3 cm, rapikan, potong rata 1.2 cm sebelum masuk ke konektor.
- Uji tester LAN: indikator lampu 1 sampai 8 harus menyala berurutan di kedua sisi.
