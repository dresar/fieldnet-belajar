# Ringkasan Cepat: Maintenance Berkala Harian, Mingguan, Bulanan

## 1. Jadwal Pemeliharaan Berkala
- Harian (5 Menit):
  - Cek suhu ruang server AC (standar 18-24°C).
  - Cek indikator titik merah rekaman di seluruh channel monitor NVR.
- Mingguan (15 Menit):
  - Buat cadangan file biner `.backup` dan file script teks `.rsc` dari MikroTik.
  - Simpan file cadangan ke flashdisk eksternal atau penyimpanan cloud luar.
- Bulanan (1 Jam):
  - Bersihkan filter kipas angin sasis dan ventilasi dengan blower antistatis (tahan bilah kipas).
  - Periksa parameter kesehatan S.M.A.R.T harddisk (Reallocated Sector Count = 0).
  - Uji ketahanan baterai UPS saat pemadaman listrik PLN simulasi (minimal 15 menit).
